<h1 align="center"> PLATAFORMA LOCAL DE IDENTIFICACIÓN ESTUDIANTIL BASADA EN RECONOCIMIENTO FACIAL USANDO EL MÉTODO ARCFACE </h1>


El reconocimiento facial es una tecnología basada en inteligencia artificial y biometría que actualmente se utiliza en diversos ámbitos, como la seguridad,
la autenticación de dispositivos y el control de accesos. En el entorno universitario, puede mejorar procesos como el registro de asistencia y la identificación 
de estudiantes, reduciendo errores y posibles suplantaciones.
Este proyecto propone desarrollar un sistema de reconocimiento facial para la Facultad de Ciencias de la Universidad Nacional de Ingeniería 
utilizando un grupo piloto de 5 estudiantes. Aunque el dataset es reducido, permite validar la metodología y demostrar que las técnicas modernas 
de aprendizaje profundo pueden ofrecer resultados confiables y escalables.
La solución se basa en ArcFace, un modelo que genera embeddings faciales altamente discriminativos, 
logrando una mejor separación entre identidades y una mayor precisión que métodos tradicionales. 

Entre sus ventajas destacan su capacidad de generalización con pocos datos, su compatibilidad con clasificadores como SVM y KNN, y su amplia implementación en herramientas modernas.
El sistema se complementa con OpenCV y MTCNN para la detección y alineación de rostros, Albumentations para aumentar el dataset, 
Scikit-learn para la clasificación y evaluación, y Flask junto con React/Bootstrap para el desarrollo de la aplicación. 
Como resultado, se obtiene un prototipo escalable que servirá como base para futuras ampliaciones a un mayor número de estudiantes e integración con sistemas institucionales.
